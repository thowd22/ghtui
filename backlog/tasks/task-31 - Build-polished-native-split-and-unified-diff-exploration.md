## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Readable diffs need more than colored text: reviewers must move quickly through files/hunks, understand changed words, and keep correct coordinates when changing display options.

## Testing steps

1. Code/provider tests: Check visual row mapping, highlighting bounds, wrapped lines, whitespace controls, viewport snapshots and canonical coordinates.
2. Real-binary TUI E2E scenario `native_diff`: Navigate/search a large diff, select the same range via keys and mouse, toggle split/context after resize, and verify selection; exercise missing/failing optional renderer fallback. Run fresh fixtures for keyboard and mouse paths and verify equivalent outcomes at 120x40 and 80x24 where applicable.
3. Run `cargo test --test tui_e2e native_diff -- --nocapture` and verify a nonzero selected test count; run the relevant code/provider tests and `cargo test --all-targets`. Record actual results and failure artifacts before completion. The initial framework is delivered by the bootstrap/framework prerequisites.
