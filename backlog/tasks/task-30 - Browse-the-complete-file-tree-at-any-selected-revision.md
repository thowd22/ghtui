## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Full repository visibility means seeing files as they were at a saved version without checking it out. Tree navigation must retain the selected revision and explain special objects.

## Testing steps

1. Code/provider tests: Test real Git trees/blobs, rename sides, directory ordering, byte paths, lazy loading, and object-type labels.
2. Real-binary TUI E2E scenario `revision_tree`: Choose an old commit, expand/collapse and open files with keys and clicks, resize/scroll, compare a renamed file, and verify working tree unchanged. Run fresh fixtures for keyboard and mouse paths and verify equivalent outcomes at 120x40 and 80x24 where applicable.
3. Run `cargo test --test tui_e2e revision_tree -- --nocapture` and verify a nonzero selected test count; run the relevant code/provider tests and `cargo test --all-targets`. Record actual results and failure artifacts before completion. The initial framework is delivered by the bootstrap/framework prerequisites.
