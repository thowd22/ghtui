## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
PR review needs a usable diff immediately without cloning. Inline reviews later require exact file/side/line coordinates unaffected by visual presentation.

## Testing steps

1. Code/provider tests: Verify patch parsing and old/new coordinates for additions, deletions, renames, multiline hunks, Unicode, and changed heads.
2. Real-binary TUI E2E scenario `pr_diff`: Open a multi-file PR, select files/hunks and a range by keys and mouse, change view/resize, and assert exact selected coordinates and no write commands. Run fresh fixtures for keyboard and mouse paths and verify equivalent outcomes at 120x40 and 80x24 where applicable.
3. Run `cargo test --test tui_e2e pr_diff -- --nocapture` and verify a nonzero selected test count; run the relevant code/provider tests and `cargo test --all-targets`. Record actual results and failure artifacts before completion. The initial framework is delivered by the bootstrap/framework prerequisites.
