## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The user wants to see all repositories in an organization and select the ones that matter. A single search page cannot be treated as a complete inventory.

## Testing steps

1. Code/provider tests: Verify multi-page inventory, duplicate/renamed repos, partial failures, inaccessible repos, and selection persistence.
2. Real-binary TUI E2E scenario `repo_catalog`: Browse a multi-page organization fixture, select repos and open one via both keys and clicks, scroll after resize, and assert the saved scope and no clone command. Run fresh fixtures for keyboard and mouse paths and verify equivalent outcomes at 120x40 and 80x24 where applicable.
3. Run `cargo test --test tui_e2e repo_catalog -- --nocapture` and verify a nonzero selected test count; run the relevant code/provider tests and `cargo test --all-targets`. Record actual results and failure artifacts before completion. The initial framework is delivered by the bootstrap/framework prerequisites.
