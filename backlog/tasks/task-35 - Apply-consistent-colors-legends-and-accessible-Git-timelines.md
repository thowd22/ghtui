## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Colors should make the tree and timeline easier to understand while retaining meaning in low-color and no-color terminals. Relations and statuses need consistent semantics across the product.

Record actual results and failure artifacts before completion. Use the shared framework established by the bootstrap/framework prerequisites.
